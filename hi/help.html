PhraseCut इस्तेमाल करें

PhraseCut learning flow को focused रखता है: एक real sentence समझें, useful pieces save करें, और भूलने से पहले review करें।

1. एक sentence analyze करें

Learn खोलें, sentence paste या type करें, language pair चुनें और analysis चलाएं। पहले पूरा meaning समझें, फिर individual words देखें।

2. उपयोगी items save करें

जब कोई sentence, word या phrase दोबारा देखने लायक हो, उसे save करें। PhraseCut saved item के साथ original sentence और translation रखता है।

3. भूलने से पहले review करें

Due items दोहराने के लिए Review खोलें। Review flow हल्का रखा गया है ताकि short reading sessions में भी फिट हो सके।

4. Library export करें

जब आपको दूसरे study workflow के लिए CSV या Anki-compatible files चाहिए हों, Library export इस्तेमाल करें।

PhraseCut install करें

iPhone, iPad और Mac के लिए PhraseCut App Store से डाउनलोड करें।
